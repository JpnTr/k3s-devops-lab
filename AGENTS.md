# Repository instructions

Read README.md, docs/rules.md and docs/todolist.md before implementation. Read the relevant design documents before changing a contract. Keep the student brief, instructor notes, detector, verifier, reset, and test aligned for every scenario. Record completed checks with actual evidence. Keep all mutations restricted to the dedicated local lab cluster. Preserve the caller's kubeconfig and current context. See docs/public-release.md before touching publication or dependency distribution.

For bug fixes, search docs/bugs.md for a matching issue first and follow its
recorded reproduction and fix approach when applicable. Record newly found bugs
and their resolution there. For bug fixes and features, update every affected
technical document and the corresponding entry in docs/todolist.md. Mark work
done only with concrete completion evidence; never infer completion from code
being authored.
