# Draft security policy — contact setup pending

The repository owner has not configured a private security reporting channel or
response timeline, so this draft is not yet an actionable vulnerability
reporting policy. Before publication, the owner should configure a private
contact and response process. Do not open a public issue containing
credentials, host identifiers, kubeconfigs, or unredacted logs. Review
diagnostics for secrets and identifiers before sharing. All workloads and
records are synthetic. The lab is designed for loopback access; never expose it
to an untrusted network.
